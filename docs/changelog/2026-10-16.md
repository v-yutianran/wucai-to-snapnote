### 实现五彩到 Snapnote 的一次运行增量备份

- 实现中国区 `7d` 全量分页、跨日 ID 去重、逐条创建与全文读回、待确认状态恢复及单机锁。

### 运行信号与边界

- 触发方式：手动执行 `python3 backup.py` 或带 `--dry-run` 预览。
- 日志来源：进程 stdout 的 JSON 事件。稳定事件为 `backup.preview`、`backup.started`、`backup.completed`、`backup.git_sync_failed`、`backup.failed`、`backup.cancelled`。
- 隔离端到端观察：预览不创建运行目录或记录；首轮备份同步合成记录；第二轮不重建笔记、不增加提交；秘密与正文不出现在日志。
- 已按 otel-spec 审查 IO、错误和脱敏边界。本地一次性 CLI 未接入 OTel SDK/Exporter，不宣称完整 Trace、Metric 或跨进程传播合规。
- 限制：只支持已核对的 Snapnote v1alpha1 JSON HTTP 契约和单机串行运行；源/目标内容或检索索引异常会保留待确认项并要求人工核对。
